# Laboratorio: Página de Perfil con CSS3 - Unidad 3

Este proyecto consiste en el desarrollo de una página web de perfil personal diseñada para consolidar conocimientos fundamentales de CSS3, incluyendo el uso de selectores avanzados, el modelo de caja, posicionamiento y estilos de formularios accesibles.

## 🛠️ Tecnologías y Herramientas

- **HTML5:** Estructura semántica (header, main, section, form, fieldset).
- **CSS3:** Implementación de Custom Properties, Flexbox, y posicionamiento avanzado.
- **VS Code:** Editor de código con extensión Live Server.
- **Git/GitHub:** Control de versiones y publicación del repositorio.

## 📂 Estructura del Proyecto

El repositorio sigue la organización de archivos y carpetas solicitada:

- `index.html`: Contenido y estructura de la página.
- `css/estilos.css`: Hoja de estilos con reset global y variables.
- `img/`: Directorio para recursos visuales (foto de perfil).
- `README.md`: Documentación del proyecto.

## 🚀 Instrucciones de Ejecución

Para visualizar el proyecto de forma local, siga estos pasos:

1. Clone este repositorio o descargue los archivos.
2. Abra la carpeta del proyecto en **Visual Studio Code**.
3. Asegúrese de tener instalada la extensión **Live Server**.
4. Haga clic derecho sobre `index.html` y seleccione **"Open with Live Server"**.

## 📝 Resumen de la Implementación

Durante el laboratorio se completaron los siguientes hitos técnicos:

- **Reset Global y Variables:** Configuración de `box-sizing: border-box` y definición de una paleta de colores institucional mediante variables CSS.
- **Header Fijo:** Uso de `position: fixed` para mantener la navegación siempre visible y `scroll-behavior: smooth` para desplazamientos fluidos.
- **Posicionamiento:** Implementación de `position: relative` en el contenedor del avatar y `position: absolute` para el badge de "CSS3".
- **Habilidades:** Estilado mediante selectores de hijo directo y modificadores BEM para diferenciar las tecnologías (HTML, CSS, JS, Java).
- **Formulario Accesible:** Diseño de campos de entrada con estados `:focus` claros, anillos de accesibilidad y transiciones en botones.
